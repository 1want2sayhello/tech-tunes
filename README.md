# Tech Tunes | Music E-Commerce UI Demo ⚡

Tech Tunes is a responsive e-commerce UI demo for discovery and purchasing vinyl records, music equipment & merch apparel.

Built with React, it features fuzzy search, URL-based sorting, persistent cart state, size-specific product variants, recently viewed products, and a simulated checkout flow.

## Key Features 🔑

- Browse vinyl, studio tech equipment, and merch through responsive product catalog and detail pages
- Search across multiple product categories and sort results by best sellers, price, or rating
- Add products to a persistent shopping cart
- Adjust quantities, remove items, review calculated totals in Cart or use a quick Buy Now flow
- Revisit previously viewed products through a paginated carousel
- Navigate various states including loading, empty, error and image fallback throughout the shopping experience.

## Technical Highlights 💡

- React, React Router, TanStack Query, SCSS Modules, & Fuse.js
- Managed global cart state with context and useReducer.
- Stored search and sorting selections in the URL
- Normalized differently shaped product data through reusable mapper functions.
- Used route-based code splitting, loading skeletons, and optimized image behavior
